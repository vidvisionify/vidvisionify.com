# 🔎 Finding Prefabs

#### <img src ="https://vrcprefabs.com/vrc_icon_notext.gif" height ="24px"> [VRCPrefabs](https://vrcprefabs.com/)

- This used to be _the_ collection of VRChat prefabs, but it seems to have fallen apart.
- Pretty sure it's not being updated anymore.
- Be skeptical of Google Drive/MEGA links, obviously.
- This might be a better way to browse: https://z3y.github.io/prefabs-browser/

#### <img src ="https://jinxxy.com/icon.png" height ="24px"> [Jinxxy](https://jinxxy.com/)

- New kid on the block! All VRChat items!
- Creators pick [how much to pay](https://support.jinxxy.com/hc/en-us/articles/16736566037389-What-are-the-Jinxxy-fees) the platform.
- Prices tend to be cheaper here as Booth + Gumroad take ~30%
- Contains mature content, behind a blur.
- The top row of items on any page is always sponsored, unrelated to your search
- There is way more AI junk here than there used to be, though it seems to be coming from certain people.

#### <img src ="https://asset.booth.pm/favicon.ico" height ="24px"> [Booth](https://booth.pm/en/items?tags%5B%5D=VRChat)

- Honestly where I've had the most luck finding assets.
- Use the VRChat tag to avoid random vroid items tripping you up.
- Item pages tend to be in Japanese, have your Google Translate ready

#### <img src ="https://assets.gumroad.com/images/pink-icon.png" height ="24px"> [Gumroad](https://gumroad.com/discover)

- Not just for VRC, but the original storefront
- Gumroad has been hostile to creators in recent years though, so people tend to be leaving.
- Check Jinxxy before you buy!
- If you do need to buy from Gumroad, make sure "\&recommended\_by=search" isn't in the url before purchase! While discovery is the only way to search, using it (with that in the url) takes money away from the individual creators!

#### <img src ="https://github.com/fluidicon.png" height ="24px"> GitHub

- Occasionally you'll find more technical projects here.
- https://github.com/madjin/awesome-vrchat - Unfortunately this is pretty dated.

#### <img src ="https://unity-assetstorev2-prd.storage.googleapis.com/cdn-origin/images/logo.png" height ="24px"> [Unity Asset Store](https://assetstore.unity.com/)

- You gotta be careful here, most things here are made for the full Unity engine and won't work with [VRChat's whitelisted world components](https://creators.vrchat.com/worlds/whitelisted-world-components/).
- Good for if you're having trouble finding an object or premade environment, but it can be a bit pricey.

#### <img src ="https://leartesstudios.com/apple-touch-icon.png" height ="24px"> [Cosmos by Leartes Studios](https://cosmos.leartesstudios.com/)

- They do have some freebies, and frequent sales!
- Occasionally [Humble Bundle](https://www.humblebundle.com/software) will run bundles with enviroments
- Not everything is ready for Unity!
- Their materials use ShaderForge, for VRC Light Volumes compatibility I end up remaking the materials with Mochie's or Poiyomi

## 🏪 Common Prefabs

Video Players

- [VideoTXL](https://github.com/vrctxl/VideoTXL) ([VPM](https://vrctxl.github.io/VPM/)) - Must use if you're planning to host events. I've found it a bit annoying to setup, try to [consult the docs](https://vrctxl.github.io/Docs/).
- [VizVid](https://github.com/JLChnToZ/VVMW) ([VPM](https://xtlcdn.github.io/vpm/)) - My current favorite, though maybe a bit too modular.
- [USharpVideo](https://github.com/MerlinVR/USharpVideo) - Hasn't been updated for a while, used to be considered the most stable.
- [ProTV](https://protv.dev/) - Regarded as fairly buggy, but version 3 is still in development. Doesn't handle streamed video well.
